# Startup Spark — AI-генератор ідей стартапів

Навчальний вебзастосунок за темою №6 із методичних вказівок. **Backend: Flask**, frontend: HTML, CSS, JavaScript; ШІ: **Google Gemini API**. Користувач вибирає сферу («Освіта», «Здоров’я», «Ігри») та отримує назву, опис і слоган стартапу в картці.

## 1. Локальний запуск на Windows

Розпакуйте ZIP, відкрийте **папку `AI_Startup_Ideas_Flask`** у VS Code та виконайте в **Terminal → New Terminal**:

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
$env:GEMINI_API_KEY = "ВАШ_НОВИЙ_API_КЛЮЧ"
.\.venv\Scripts\python.exe app.py
```

Відкрийте **http://127.0.0.1:5000/**. Термінал має залишатися відкритим, поки сайт працює. Зупинити — `Ctrl+C`.

**Ключ беріть із [Google AI Studio](https://aistudio.google.com/api-keys)**. Не надсилайте його в чат, не додавайте до коду, GitHub, звіту або відео. Старий скомпрометований ключ необхідно відкликати. Якщо раніше створювали `.venv` для попереднього проєкту, тут створіть нове середовище.

Модель за замовчуванням — `gemini-3.5-flash-lite`. За потреби виберіть іншу доступну для власного API-проєкту:

```powershell
$env:GEMINI_MODEL = "НАЗВА_ДОСТУПНОЇ_МОДЕЛІ"
```

Нова модель застосовується після перезапуску сервера. При помилці **503** сервіс може бути тимчасово перевантажений; застосунок автоматично повторює запит один раз.

## 2. Перевірка коду

```powershell
.\.venv\Scripts\python.exe -m unittest -v test_app.py
```

Тести перевіряють Flask-маршрути, HTML/CSS і формат відповіді, **підмінюючи** Gemini API. Для підтвердження реальної ШІ-генерації потрібен окремий успішний запит із браузера.

## 3. Публікація на Render

> Публікація — окрема дія, її неможливо виконати одним запуском на localhost. Потрібні ваші облікові записи GitHub та Render. Перевірте доступність безкоштовного тарифу під час реєстрації та не погоджуйтеся на платний план без потреби.

1. Створіть новий GitHub-репозиторій (наприклад, `startup-spark-ai`) та завантажте **файли з папки проєкту**; секрети й `.venv` не додавайте. `render.yaml` можна залишити в репозиторії.
2. Відкрийте https://dashboard.render.com/ → **New → Web Service**, підключіть GitHub та оберіть репозиторій.
3. Вкажіть **Language/Runtime: Python**, **Build Command: `pip install -r requirements.txt`**, **Start Command: `gunicorn app:app`**. Якщо доступно, виберіть **Free** instance. Цей же процес налаштовується через Blueprint із `render.yaml`.
4. У розділі **Environment** додайте змінну `GEMINI_API_KEY` зі своїм **новим** API-ключем. За бажанням додайте `GEMINI_MODEL=gemini-3.5-flash-lite` (або модель, доступну вашому проєкту). Ключ **не** додавайте до GitHub.
5. Після успішного розгортання Render дасть публічне посилання виду `https://...onrender.com`. Відкрийте його в іншому браузері та перевірте реальну генерацію.
6. Запишіть коротке демо (приблизно 30–60 с): покажіть публічну адресу, вибір теми, натискання «Згенерувати ідею» і результат з назвою, описом та слоганом. Завантажте відео на Google Drive із доступом за посиланням.
7. Додайте **два посилання** до звіту: на сайт Render і на відеодемо Google Drive.

*Безкоштовні Render-сервіси можуть засинати після бездіяльності. API Gemini має власні квоти й обмеження.*

## 4. Структура

- `app.py` — Flask backend, маршрут `/generate`, Gemini API.
- `templates/index.html` — форма та картка результату.
- `static/style.css` — оформлення сторінки.
- `requirements.txt` — Flask, Gemini SDK, Gunicorn.
- `test_app.py` — локальні автотести без витрат API.
- `render.yaml` — налаштування безкоштовної служби Render, ключ вводиться окремо.
- `.gitignore` — запобігає публікації віртуального середовища й локальних файлів.

## 5. Що показати викладачу

- Сайт за **публічним посиланням**, не `127.0.0.1`.
- Принаймні одну **успішну реальну AI-генерацію**, не заглушку.
- Коротке **відеодемо** з адресою сайту та роботою генератора.
